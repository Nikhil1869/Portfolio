# The Developer Paddock

My personal portfolio website, inspired by Formula 1, showcasing my projects, technical skills, experience, and open-source contributions.

Built with a focus on simplicity, interactivity, and responsive design.

## About Me

I'm **Devathi Nikhil Suraj**, a Computer Science and Engineering student at CVR College of Engineering, Hyderabad.

I enjoy identifying problems and exploring ways to solve them through software. I'm interested in full-stack development, AI/ML, and open-source contributions.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **3D & Animations:** Three.js, React Three Fiber, GSAP
- **Deployment:** Vercel

## Features

- Formula 1-inspired design
- Interactive 3D racing car
- Smooth animations and transitions
- Interactive project showcase
- Open-source contributions
- Responsive design
- Resume download and contact links

## Run Locally

Make sure Node.js 22.12 or newer is installed.

```bash
git clone https://github.com/Nikhil1869/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
